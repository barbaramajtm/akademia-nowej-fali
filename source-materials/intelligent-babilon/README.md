## System (4 fazy)

1. **PRIME** — szampon oczyszczający przygotowujący włos  
2. **TREATMENT** — kuracja białkowo-keratynowa (głębsze włókna); 2–3 min, **bez spłukiwania**  
3. **BUILD UP** — fluid na zewnętrzną strukturę (długości/końce); 1 min, spłukać  
4. **CLOSER** — fluid leave-in zamykający kurację; też do domu  

**UWAGA z instrukcji:** I, II, III przed koloryzacją; IV po koloryzacji.
